# 2026-11-05

## Type-aware baseline additions (`await-thenable`, `no-floating-promises`, `switch-exhaustiveness-check`)

- Added `typescript/await-thenable`, `typescript/no-floating-promises`, and `typescript/switch-exhaustiveness-check` to `typescriptTypeAwareRules` in `src/oxlint/rules.mjs`.
- Previously, `typescriptTypeAwareRules` enabled `typescript/no-misused-promises` (catching Promises in conditionals and `forEach`), leaving bare unawaited Promise expression statements (`no-floating-promises`), `await` on synchronous values (`await-thenable`), and union `switch` statements without `default:` that omit a union variant (`switch-exhaustiveness-check`) uncovered.
- Extended `scripts/verify-consumer.mjs` to assert that all three rules reject violations in the `full` tier across both supported Oxlint versions while remaining inert in the `syntax-only` tier.

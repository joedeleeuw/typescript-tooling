## Playwright recommended rules (`playwrightFiles`)

- `/eslint` `createConfig({ playwrightFiles })` applies `eslint-plugin-playwright` 2.12's `flat/recommended` (its own severities) to the listed repository-relative patterns. No list, no Playwright rules.
- Scoped by file, not repo-wide or through the oxlint ecosystem catalog: the plugin identifies `expect` by name, so a repo-wide block reads vitest `expect` as Playwright's. Homer's first measurement flagged 23 `no-standalone-expect` hits in vitest files under a directory that also holds Playwright scripts; consumers list the files that drive Playwright.
- No ESLint plugin exists for raw CDP. The gap there is typing, not lint: a session wrapper that widens `send` params to the union of every command and returns `unknown` loses the per-method protocol types Playwright's `CDPSession` already carries.
- `scripts/verify-consumer.mjs` proves the packed artifact rejects `waitUntil: "networkidle"` inside a listed pattern, accepts the same code outside it under `--max-warnings=0`, and rejects a pattern that leaves the repository.
